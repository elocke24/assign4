How to Play

1. Choose a screen name to get started. If someone else is already using it, try a different one!

2. You can start a game as X or O, or join someone who's already waiting to play.

3. Take turns placing your Xs and Os. The first player to get 3 in a row wins!

4. You can start a new game after each match.
